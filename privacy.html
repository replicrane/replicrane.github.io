RepliCrane

プライバシーポリシー

2026-10-16

このページは、RepliCrane の開発者が自分の SNS アカウントの運用に使う道具「RepliCrane Autopost」の扱う情報について書いたものです。この道具は一般の利用者には提供していません。

使う情報

  • 開発者自身の YouTube チャンネル、Instagram アカウント、TikTok アカウントへの投稿の権限
  • それらの投稿の再生数・いいね・コメント数・保存数・シェア数・視聴時間などの集計の数字

ほかの人のアカウントの情報、視聴者個人を特定できる情報は集めません。

使い道

ゲームの紹介動画を予約どおりに投稿し、投稿ごとの反応を集計して、次の動画の作り方を決めるためだけに使います。

保存と共有

  • 数字と認証の情報は、開発者の手元のコンピューターにだけ保存します
  • 第三者に売ったり、渡したりしません。広告にも使いません
  • 投稿の予約には Zernio、動画の一時的な置き場所には Cloudinary を使います。どちらも投稿のためだけに使い、投稿が済んだ動画は削除します

Google のデータについて

YouTube API Services から受け取ったデータの使い方と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。この道具は YouTube 利用規約に従って YouTube API Services を使います。Google のプライバシーポリシーは こちらです。許可は Google アカウントの権限のページからいつでも取り消せます。

削除

許可を取り消すと、この道具はそのアカウントのデータを読めなくなります。手元に保存した数字は、問い合わせがあれば 30 日以内に削除します。

問い合わせ

replicrane@gmail.com

Privacy Policy

"RepliCrane Autopost" is an internal tool the RepliCrane developer uses to run the developer's own social media accounts. It is not offered to the public.

Data used

  • Permission to post to the developer's own YouTube channel, Instagram account and TikTok account
  • Aggregate numbers for those posts: views, likes, comments, saves, shares and watch time

The tool does not collect data about other accounts or anything that identifies individual viewers.

Purpose

To publish the game's videos on schedule and to measure how each post performs, so the next video can be planned.

Storage and sharing

Numbers and credentials are stored only on the developer's own computer. They are never sold, shared with third parties or used for advertising. Zernio is used to schedule posts and Cloudinary to hold a video briefly until it is published; videos are deleted after publishing.

Google user data

Use and transfer of information received from YouTube API Services adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services and is bound by the YouTube Terms of Service. See the Google Privacy Policy. Access can be revoked at any time at Google account permissions.

Deletion

After access is revoked the tool can no longer read the account. Stored numbers are deleted within 30 days on request.
